# LiftLoop

A personal, single-user, mobile-first workout logger. Goal-first logging: the app tells you one goal per exercise, you do the set, you tap once.

The code is public; the data is private. The app is protected by a single passcode and runs on free tiers (Vercel Hobby + Neon Free).

Status: in development. See `docs/superpowers/specs/` for the design spec and `docs/superpowers/plans/` for the build plan.
